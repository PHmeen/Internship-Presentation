Acquired Tech Stack & Development Pipeline

เครื่องมือและเทคโนโลยีหลักที่ใช้งาน

ความสัมพันธ์ของระบบการพัฒนาและการรับส่งข้อมูลจริง แสดงเป็นขั้นตอนที่เข้าใจง่ายและถูกต้องชัดเจน

CLIENT SIDE (FRONTEND)
TypeScript
ควบคุมความปลอดภัยของประเภทข้อมูลระบบ
Next.js Framework
จัดการโครงสร้างหน้าเว็บและอินเทอร์เฟซจองอาหาร
PHP (Frontend UI)
เรนเดอร์หน้าแค็ตตาล็อกสินค้า STSP Innomart
SERVER SIDE (BACKEND)
PHP 8.2 Backend API
รัน API ประมวลผลเบื้องหลังระบบและแอดมินพาเนล
SQLite3 Database
จัดเก็บข้อมูลลงไฟล์เดี่ยวที่มีความเสถียรสูง
CLOUD DELIVERY (CI/CD)
GitHub Repository
ควบคุมเวอร์ชันซอร์สโค้ดกลางร่วมกับทีมงาน
Vercel Deployment
ระบบโฮสต์โปรเจกต์และควบคุมการบิลด์อัตโนมัติ
💡 เส้นเชื่อมต่อคำนวณตำแหน่งจริงขององค์ประกอบแบบ Real-time
