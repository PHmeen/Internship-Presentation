Challenges & Solutions

ปัญหาและอุปสรรคระหว่างฝึกงาน

PROBLEM 01

ไม่คุ้นเคยกับเครื่องมือและสภาพแวดล้อม

ในช่วงเริ่มต้น ไม่คุ้นเคยกับเครื่องมือและระบบที่ใช้พัฒนา ทำให้ต้องใช้เวลาศึกษาเรียนรู้ค่อนข้างมาก ส่งผลให้การเริ่มงานจริงในช่วงแรกช้ากว่าที่คาดการณ์ไว้

RESOLUTION

ศึกษาเพิ่มเติมและฝึกฝนทดลองใช้งานจริง

ศึกษาค้นคว้าเพิ่มเติมจากแหล่งเรียนรู้ออนไลน์ เรียนรู้วิธีการทำงานร่วมกันผ่าน Git และลองสร้างแบบจำลองการเชื่อมต่อจนมั่นใจ ทำให้การพัฒนาเดินหน้าได้อย่างราบรื่น

PROBLEM 02

สถาปัตยกรรมและตรรกะระบบมีความซับซ้อน

เมื่อโปรเจกต์ขยายตัว การเชื่อมประสานฝั่งหน้าเว็บ การคำนวณราคา สินค้าคงคลัง และระบบหลังบ้านมีความซับซ้อนสูง ทำให้เสี่ยงต่อการเกิดข้อผิดพลาดในการเชื่อมต่อข้อมูล

RESOLUTION

ย่อยสถาปัตยกรรมออกเป็นโมดูล

จัดการแบ่งโครงสร้างไฟล์ แบ่งภาระหน้าที่ (Single Responsibility) ในแต่ละ API และเขียนเอกสารกำกับอย่างเป็นลำดับ ทำให้ควบคุมระบบง่ายขึ้นและต่อเติมฟีเจอร์ใหม่ได้รวดเร็ว

PROBLEM 03

การสืบค้นและค้นหาบั๊กทางเทคนิคใช้เวลาสูง

เมื่อพบข้อผิดพลาดที่ไม่เคยเจอหรือมีความแปรผันของสภาพแวดล้อม (Environment variation) การวิเคราะห์ด้วยวิธีเดิมอาจใช้เวลานานและทำให้งานสะดุดลง

RESOLUTION

ประยุกต์เครื่องมือตรวจสอบและ AI Co-Pilot

ใช้ระบบดีบักเกอร์เบราว์เซอร์ วิเคราะห์ Error logs ร่วมกับเครื่องมือ AI ช่วยแยกแยะสาเหตุและหาวิธีการแก้ปัญหาที่ตรงจุด ช่วยร่นระยะเวลาแก้ไขจุดบกพร่องลงอย่างมาก
