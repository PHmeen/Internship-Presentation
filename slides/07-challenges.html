Challenges & Solutions

ปัญหาและอุปสรรคระหว่างฝึกงาน

สรุปความท้าทายเชิงเทคนิคที่พบระหว่างการพัฒนาระบบ
พร้อมกระบวนการวิเคราะห์และแก้ไขปัญหาอย่างเป็นระบบ (Problem-Solving Process)

THE CHALLENGE
01

ข้อจำกัดนโยบายความปลอดภัย (CORS)

พบปัญหาเบราว์เซอร์ระงับสิทธิ์การเข้าถึงทรัพยากรเมื่อรันระบบผ่านไฟล์สแตติก (file://) ทำให้ไม่สามารถโหลดคอมโพเนนต์ย่อยแบบไดนามิกได้

THE RESOLUTION

พัฒนาสภาพแวดล้อมจำลอง (Local Server)

เขียนสคริปต์ Node.js Server แบบ Zero-dependency เพื่อจำลองโฮสต์เสมือนจริง ช่วยปลดล็อกการเข้าถึงไฟล์ และทำให้การทดสอบระบบลื่นไหล

THE CHALLENGE
02

ความไม่สอดคล้องของระบบอัตลักษณ์ (UI)

คอมโพเนนต์ต่างๆ ในระบบขาดมาตรฐานกลาง ทั้งการใช้โทนสี ขนาดฟอนต์ และระยะห่าง ทำให้ภาพรวมของการแสดงผลขาดความน่าเชื่อถือ

THE RESOLUTION

วางระบบมาตรฐานการออกแบบ (Design Tokens)

กำหนด Single Source of Truth ผ่านไฟล์ CSS Variables เพื่อรวมศูนย์การตั้งค่า UI ช่วยให้ระบบเป็นมาตรฐานเดียวกันและง่ายต่อการแก้ไขในอนาคต
