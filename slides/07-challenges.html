ปัญหาที่ 01

ข้อจำกัด CORS ของเบราว์เซอร์

ระบบความปลอดภัยของเบราว์เซอร์ป้องกันการดึงไฟล์ HTML ย่อยมาประกอบกันผ่าน JavaScript เมื่อเปิดผ่านโปรโตคอล file://

✓ แนวทางแก้ไข
เขียน Local Server ด้วย Node.js (server.js) ไม่มี Dependencies จำลองโฮสต์ที่ localhost:3000

ดีไซน์และสไตล์ไม่สอดคล้องกัน
