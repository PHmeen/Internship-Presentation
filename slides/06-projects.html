เทคโนโลยีหลัก: PHP & SQLite3

โครงสร้างฐานข้อมูลน้ำหนักเบาและเสถียร

พัฒนาระบบหลังบ้านด้วยภาษา PHP เพื่อจัดการข้อมูลเว็บไซต์ STSP Innomart และจัดทำโครงสร้าง SQLite3 สำหรับจัดการระบบจองอาหารห้องประชุมของอุทยานวิทยาศาสตร์ ม.อ.

  • ระบบ SQLite3 Engine: จัดเก็บข้อมูลได้เบา ติดตั้งง่าย ไม่จำเป็นต้องรัน Database Server แยก
  • PHP Admin Controls: สร้างหน้าควบคุมการทำรายการ ข้อมูลสินค้า และสิทธิ์การเข้าถึงข้อมูลอย่างรัดกุม
